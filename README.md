# Groundwater_DOM_convergence
R scripts used in data processing and visualization for manuscript "Converging molecular composition of groundwater dissolved organic matter across contrasting aquifer systems"
submitted to Environmental Science and Technology
The depository includes the following scripts:
1) HRMS recalibration, denoising, blank subtraction and molecular formula assignment script: MF_assignment_and_processing.R The .mzML HRMS data files are available in Zenodo repository under: 10.5281/zenodo.22658902 
2) Main DOM data processing script including visualization for main text and supplementary information: Ubiq_MFs.R
3) Water chemistry data processing: water_chem_dispersal.R
4) Tandem mass spectrometry data processing: ms1_ms2_pipeline.R

Additionally, the csv file dataref_new.csv with information about sampling campaign number (PNK) at a given site H (Hainich CZE) or S (SESO) and its date is available in repository.
